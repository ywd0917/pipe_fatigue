# Rainflow 피로 분석 프로젝트

상수도 파이프 압력 데이터의 Rainflow Counting 분석을 통한 피로 손상 평가

## 스크립트

- [main51_find_freq.py](docs/main51_find_freq.md) - 주파수 성분 분석 및 분리 주파수 결정
- [main52_pass_filter.py](docs/main52_pass_filter.md) - V자 최저점 기준 Pass Filter 적용 및 시각화
- [main53_rainflow.py](docs/main53_rainflow.md) - 압력 데이터 Rainflow 분석 및 피로 손상 계산

# main51_find_freq.py

## 개요
압력 데이터의 주파수 성분 분석 및 필터 설계 - 파형의 주요 주파수 성분을 추출하고 최적 high, low 분리 지점을 찾음

## 실행 방법
```bash
python main51_find_freq.py
```

## 입력 데이터
**위치:** `data/raw/`

6개 압력 데이터 CSV 파일 (총 ~46 MB):
- 0243 소구역 압력 데이터.csv
- 0461 소구역 압력 데이터.csv
- 0470 소구역 압력 데이터.csv
- 0480 소구역 압력 데이터.csv
- 0490 소구역 압력 데이터.csv
- 0520 중구역 압력 데이터.csv

**데이터 형식:**
- 컬럼: `msrmt_dt` (DateTime), `wtrprsr` (Pressure)
- 샘플링 간격: 5분
- 기간: 2022-08-20 ~ 2025-08-31

## 출력 결과
**위치:** `results/main51/`

### 생성 파일 (7개)
1. **주파수 스펙트럼 그래프** (6개 PNG)
   - `frequency_spectrum_*.png` (각 지역별)
   - Log/Linear 스케일 파워 스펙트럼
   - 주요 피크 표시 (주파수, 주기, 파워)
   - V자형 밸리 포인트 표시

2. **성분 분리 분석** (1개 PNG)
   - `component_separation_analysis.png`
   - 6패널 종합 분석: 파워 스펙트럼, 원본 신호, 분리된 성분

## 분석 과정

1. **데이터 전처리**
   - CSV 파일 읽기
   - 시간순 정렬
   - NaN 값 선형 보간

2. **Power Spectrum 분석** (Welch's method)
   - Window: Hann, 4096 samples (~14.2일)
   - Overlap: 50%
   - DC 성분 제거

3. **피크 검출**
   - 방법: scipy.signal.find_peaks
   - Prominence 임계값: 0.5% of max PSD
   - 파워 기준 내림차순 정렬

4. **주요 성분 추출**
   - 상위 2개 피크 선택
   - 일반적 결과:
     - 성분 1: 0.000011 Hz (1462.9분, 일주기)
     - 성분 2: 0.000023 Hz (731.4분, 반일주기)

5. **V자형 밸리 포인트 검출**
   - 고주파 피크 오른쪽에서 최저점 탐색
   - 이 지점이 최적 필터 cutoff 주파수
   - **0520 지역 결과**: 0.000030 Hz (553.5분) → 시스템 표준

6. **필터 설계**
   - Low Pass Filter: 저주파 성분 추출
   - High Pass Filter: 고주파 성분 추출
   - Butterworth 4차 필터

7. **성분 분리 시각화**
   - 원본 신호에서 2개 성분 분리
   - 각 성분의 특성 확인

## 주요 결과 해석

### 검출되는 주파수 성분

| 성분 | 주파수 | 주기 | 의미 |
|------|--------|------|------|
| **일주기** | 0.000011 Hz | ~1463분 (24.4시간) | 일상 사용 패턴 (아침/저녁 피크) |
| **반일주기** | 0.000023 Hz | ~731분 (12.2시간) | 2회/일 변동 패턴 |

### V자형 밸리 (V-shaped Valley)

- **정의**: 두 주요 피크 사이의 최저점
- **의미**: 성분 간 간섭이 최소화되는 지점
- **활용**: 이 주파수를 기준으로 Low/High Pass Filter 설계
- **표준값**: 553.5분 (9.23시간) - 0520 지역 기준

### 실무 활용

1. **필터 설계 기준**
   - main52_pass_filter.py에서 사용할 cutoff 주파수 결정

2. **운영 패턴 파악**
   - 일주기/반일주기 성분의 강도 비교
   - 지역별 사용 패턴 차이 분석

3. **이상 탐지**
   - 예상과 다른 주파수 피크 출현 시 시스템 이상 의심

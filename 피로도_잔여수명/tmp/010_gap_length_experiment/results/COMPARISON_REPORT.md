## 🔍 분석

### 1. 가설 검증 결과

**가설**: Gap 길이 ↓ → R² ↑ (보간 성능 향상)

**결과**: ❌ **가설 기각**

```
예상:
3일  → R² 0.6-0.8
7일  → R² 0.4-0.6
14일 → R² 0.2-0.4
24일 → R² -0.04 (확인됨)

실제:
3일  → R² -0.15 ❌ (예상보다 0.75-0.95 낮음!)
7일  → R² -0.09 ❌ (예상보다 0.49-0.69 낮음!)
14일 → R² -0.05 ❌ (예상보다 0.25-0.45 낮음!)
24일 → R² -0.04 ✓ (예상 일치)
```

### 2. Gap 길이와 R²의 관계

**관찰**:
```
R² (XGBoost)

   0.0 ┤
       │
 -0.05 ┤               ●──────●
       │           ●
 -0.10 ┤       ●
       │
 -0.15 ┤   ●
       │
       └───┴───┴───┴───┴───
          3   7  14     24  (일)
```

**패턴**: Gap 길이 ↓ → R² 약간 개선되지만 **여전히 모두 음수**

**해석**:
- Gap 3일: R² -0.15 (평균보다 15% 더 나쁨)
- Gap 24일: R² -0.04 (평균보다 4% 더 나쁨)
- **Gap을 줄여도 성능이 양수(+)로 전환되지 않음!**

### 3. 왜 3일도 실패했는가?

#### 기대했던 시나리오
```
[정상] → [3일 gap] → [정상]
         ^^^^^^^^^^
         짧아서 전후 연속성 유지 → 보간 가능
```

#### 실제 시나리오
```
[노이즈 같은 변동] → [3일 gap] → [노이즈 같은 변동]
                     ^^^^^^^^^^
                     연속성 없음 (ACF 0.145) → 보간 불가능
```

#### 근본 원인
1. **시간 의존성 극히 약함** (ACF 0.145)
   - 5분 전 값과 현재 값의 상관: 0.145
   - 1시간 전 상관: 0.176
   - **3일 전 상관: 거의 0에 가까움**

2. **변동이 랜덤에 가까움**
   - Daily variation: 0.02 (극히 작음)
   - Periodicity: 0.003 (거의 없음)
   - **압력이 불규칙하게 요동침 → 예측 불가능**

3. **모델이 학습할 패턴 부재**
   - XGBoost: 시간 features로 패턴 학습 시도 → 실패
   - Prophet: Seasonality 분해 시도 → 노이즈만 학습
   - Linear: 전후 연결 시도 → 중간 변동 못 따라감

## 🎯 모델별 분석

### XGBoost (가장 덜 나쁨)

**성능**:
- 3일: R² -0.15, MAE 0.06
- 24일: R² -0.04, MAE 0.06

**관찰**:
- MAE는 일정 (0.06 근처)
- Gap이 길어질수록 R²이 약간 개선 (!)
- **이유**: 24일이 더 평균에 가까운 예측

**결론**: XGBoost는 항상 평균 근처만 예측

### Prophet (최악)

**성능**:
- 3일: R² -1.00, MAE 0.09
- 24일: R² -4.37, MAE 0.17

**관찰**:
- Gap이 길어질수록 성능 급격히 악화
- Trend가 잘못된 방향으로 학습
- 3일도 평균보다 2배 나쁨

**결론**: Prophet은 이 데이터에 완전히 부적합

### Linear (중간)

**성능**:
- 3일: R² -0.70, MAE 0.08
- 14일: R² -0.59, MAE 0.09
- (24일 미측정)

**관찰**:
- 직선 연결이지만 XGBoost/Prophet보다는 나음
- Gap 길이에 영향 적게 받음

**결론**: 복잡한 모델보다 단순 모델이 나음

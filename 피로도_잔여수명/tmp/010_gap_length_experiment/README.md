**가설**: Gap 길이 ↓ → R² ↑ (보간 성능 향상)

- **대상**: 0243 지역 (결측 0개, 원본 비교 가능)

- **Gap 길이**: 3일, 7일, 14일, (24일 완료)
- **모델**: XGBoost, Prophet, Linear Interpolation

## 🎯 의사결정 기준

### 시나리오 A: 3일 gap 성공 (R² > 0.7)
→ ✅ **main41 구현** (3일 이하 gap에 XGBoost 적용)
→ 경고: "3일 초과 시 정확도 저하"

### 시나리오 B: 7일 gap만 성공 (R² > 0.5)
→ ⚠️ **조건부 적용** (7일 이하, 신뢰구간 표시)
→ 강한 경고: "7일 초과 비권장"

### 시나리오 C: 모두 실패 (R² < 0.5)
→ ❌ **보간 포기**
→ Gap 허용 또는 Linear만 제공 (경고 포함)

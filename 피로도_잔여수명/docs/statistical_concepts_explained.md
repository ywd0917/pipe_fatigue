# 📊 통계 지표 쉽게 이해하기

파이프 재작업 분석에서 자주 나오는 통계 용어들을 일반인도 이해할 수 있도록 설명합니다.

## 📈 r (상관계수, Correlation Coefficient)

### "두 변수가 얼마나 함께 움직이는가?"

**일상적 비유**: 두 친구가 얼마나 비슷하게 행동하는지 측정

#### 상관계수 값의 의미

| r 값 | 의미 | 실제 예시 |
|------|------|----------|
| **r = 1.0** | 완벽한 양의 관계 | 기온 올라가면 아이스크림 판매 항상 증가 |
| **r = 0.5** | 중간 정도 양의 관계 | 공부 시간과 성적 (대체로 비례) |
| **r = 0** | 전혀 관계없음 | 신발 사이즈와 시험 점수 |
| **r = -0.5** | 중간 정도 음의 관계 | TV 시청 시간과 운동 시간 |
| **r = -1.0** | 완벽한 음의 관계 | 남은 돈과 쓴 돈의 관계 |

#### 본 프로젝트에서의 예시
```
K_soil과 재작업: r = 0.0376
→ 거의 관계없음 (3.8% 정도만 함께 움직임)
→ 토양 조건과 재작업 발생이 별로 연관이 없다
```

## 📐 p-value (유의확률)

### "관찰된 결과가 우연일 확률"

**일상적 비유**: 동전 던지기에서 앞면이 10번 연속 나올 확률처럼, 관찰된 패턴이 그냥 운이었을 가능성

#### p-value 해석 기준

| p 값 | 의미 | 판단 | 비유 |
|------|------|------|------|
| **p < 0.001** | 0.1% 미만 | 매우 확실함 ⭐⭐⭐ | 로또 당첨될 확률보다 낮음 |
| **p < 0.01** | 1% 미만 | 확실함 ⭐⭐ | 주사위로 6이 3번 연속 나올 확률 |
| **p < 0.05** | 5% 미만 | 유의미함 ⭐ | 동전 앞면 5번 연속 확률 |
| **p > 0.05** | 5% 이상 | 유의미하지 않음 ❌ | 우연일 가능성 있음 |
| **p > 0.1** | 10% 이상 | 신뢰할 수 없음 ❌❌ | 아마 그냥 우연 |

#### 본 프로젝트에서의 예시
```
K_soil의 p = 0.2834 (28.34%)
→ 이 관계는 그냥 우연일 가능성이 28%나 됨
→ 통계적으로 의미 없는 관계
```

---

## 📊 R² (결정계수, Coefficient of Determination)

### "한 변수가 다른 변수를 얼마나 설명하는가?"

**일상적 비유**: 시험 문제 100문제 중 몇 문제를 맞췄는지와 같은 개념

#### R² 값의 의미

| R² 값 | 설명력 | 실제 의미 | 학교 성적 비유 |
|-------|--------|-----------|----------------|
| **R² = 100%** | 완벽한 설명 | 모든 변동을 설명 가능 | 100점 만점 |
| **R² = 70%** | 높은 설명력 | 대부분 설명 가능 | 70점 (양호) |
| **R² = 30%** | 보통 설명력 | 일부만 설명 가능 | 30점 (과락) |
| **R² = 10%** | 낮은 설명력 | 거의 설명 못함 | 10점 (낙제) |
| **R² < 3%** | 매우 낮은 설명력 | 사실상 쓸모없음 | 3점 (...)  |

#### 본 프로젝트에서의 예시
```
K-factors의 R² < 3%
→ K-factors로는 재작업 패턴의 3%도 설명 못함
→ 97% 이상은 다른 요인 때문
→ 마치 날씨로 주식 가격을 예측하려는 것과 같음
```

---

## 🔗 r, p, R²의 관계

### 세 지표는 서로 연관되어 있지만 다른 것을 측정합니다

| 지표 | 측정 내용 | 질문 |
|------|-----------|------|
| **r** | 관계의 방향과 강도 | "얼마나 강하게 연결되어 있나?" |
| **p** | 통계적 신뢰도 | "이게 진짜일까, 우연일까?" |
| **R²** | 설명력의 크기 | "얼마나 잘 예측할 수 있나?" |

### 실제 상황별 해석

#### 📌 케이스 1: "확실하지만 쓸모없는 관계"
```
r = 0.1 (약한 양의 상관)
p = 0.001 (매우 유의미)
R² = 1% (설명력 매우 낮음)
```
**해석**: "관계는 확실히 있지만, 예측에는 거의 도움 안 됨"
**비유**: 매일 아침 커피 마시면 확실히 기분이 좋아지지만(p<0.001), 하루 전체 행복의 1%만 설명(R²=1%)

#### 📌 케이스 2: "강해 보이지만 믿을 수 없는 관계"
```
r = 0.6 (강한 양의 상관)
p = 0.3 (유의미하지 않음)
R² = 36% (설명력 높아 보임)
```
**해석**: "데이터가 적어서 우연히 높게 나온 것일 수 있음"
**비유**: 친구 3명만 조사했더니 키 큰 사람이 다 농구를 잘함(R²=36%), 하지만 우연일 가능성 높음(p=0.3)

#### 📌 케이스 3: 본 프로젝트의 실제 사례 (0490 지역)
```
K_repair 분석 결과:
r = 0.249 (약한 양의 상관)
p < 0.001 (매우 유의미)
R² = 6.2% (낮은 설명력)
```
**해석**: 
- ✅ 관계는 확실히 존재 (p < 0.001)
- ⚠️ 하지만 재작업의 6.2%만 설명 가능
- 💡 **실무적 의미**: "K_repair는 참고 지표로만 사용하고, 다른 94%를 설명할 요인을 찾아야 함"

## 🎯 실무 활용 가이드

### 의사결정을 위한 체크리스트

1. **p-value 확인** → 0.05 미만인가?
   - ❌ NO: 통계적으로 의미 없음, 무시
   - ✅ YES: 다음 단계로

2. **R² 확인** → 10% 이상인가?
   - ❌ NO: 예측력 너무 낮음, 보조 지표로만 활용
   - ✅ YES: 다음 단계로

3. **r 확인** → 절대값이 0.3 이상인가?
   - ❌ NO: 관계가 너무 약함
   - ✅ YES: 실무에 활용 가능

### 본 프로젝트 결론

**K-factors 분석 결과 요약**:
- 대부분의 K-factors: p > 0.05 (통계적으로 무의미)
- 유의미한 경우도: R² < 10% (설명력 부족)
- **권고사항**: K-factors는 주요 의사결정 도구로 부적합, 보조 참고 자료로만 활용

**더 중요한 요인들**:
- 시공 품질
- 유지보수 이력
- 외부 충격 (공사, 사고 등)
- 파이프 연결부 상태

---

## 💡 기억해야 할 핵심

1. **p가 크면 (>0.05)** → "믿을 수 없는 관계"
2. **R²가 작으면 (<10%)** → "예측에 쓸모없는 관계"
3. **둘 다 만족해야** → 실무에 활용 가능

> 💭 **최종 팁**: 통계는 도구일 뿐입니다. 숫자보다 중요한 것은 현장 경험과 도메인 지식입니다. 통계 결과가 현실과 맞지 않다면, 데이터나 분석 방법을 다시 검토해보세요.

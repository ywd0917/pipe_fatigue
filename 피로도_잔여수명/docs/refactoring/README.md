# 리팩토링 문서

이 폴더는 프로젝트의 리팩토링 관련 문서를 포함합니다.

## 📁 문서 구조

### [GUIDE.md](./GUIDE.md)
코드 리팩토링의 핵심 가이드라인을 정의합니다. 코드를 세 가지 범주(공통 코드, 특화 코드, 프로젝트 코드)로 분류하고 각각의 리팩토링 원칙을 설명합니다.

### [REFACTORING_DETAILS.md](./REFACTORING_DETAILS.md)
구체적인 리팩토링 계획과 실행 방법을 담고 있습니다:
- 3단계 코드 재편성 전략 (최우선 과제)
- Phase별 실행 계획
- 리팩토링 체크리스트
- 도구 활용 방법

### [SEPARATION_GUIDE.md](./SEPARATION_GUIDE.md)

- 분리가 필요한 경우와 불필요한 경우의 명확한 기준
- 실제 사례를 통한 적절한 분리 수준 예시
- 과도한 분리를 피하고 가독성을 유지하는 방법

## 🎯 리팩토링 목표

1. **코드 구조 개선**: 3개 범주로 코드를 명확히 분리
2. **가독성 향상**: 메인 함수에서 전체 흐름을 한눈에 파악
3. **재사용성 증대**: 공통 코드의 독립성 확보
4. **유지보수성 강화**: 특화 코드의 응집도 향상

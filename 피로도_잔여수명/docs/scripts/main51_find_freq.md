# main51_find_freq.py - 주파수 성분 분석 및 V자 최저점 검출

## 개요
압력 데이터의 주파수 성분을 분석하여 주요 두 개의 파형 성분을 추출하고, V자 최저점을 검출하는 스크립트입니다.

## 주요 기능
- **파워 스펙트럼 분석**: Welch 방법을 이용한 주파수 스펙트럼 계산
- **주요 피크 검출**: 주된 두 개의 주파수 성분 자동 식별
- **V자 최저점 검출**: 오른쪽 피크에서 내려가다가 다시 올라가는 지점 탐지
- **성분 분리 필터 설계**: 저대역/고대역 성분 분리를 위한 필터 파라미터 도출
- **시각화**: 로그/선형 스케일 주파수 스펙트럼 및 성분 분리 결과 그래프

## 입력 파일

## 데이터 처리 흐름
1. 압력 데이터 로드 (5분 간격)
2. 주파수 분석 및 V자 최저점 검출
3. 주요 피크 검출 및 성분 식별
4. 성분 분리를 위한 필터 파라미터 도출

## 알고리즘 세부사항

### 1. 데이터 전처리
- NaN 값 선형 보간 처리
- 샘플링 주파수: 1/300 Hz (5분 간격)

### 2. 주파수 분석
- **방법**: Welch's method
- **파라미터**:
  - nperseg: 4096 (약 14.2일의 윈도우)
  - overlap: 50%
  - window: Hann window

### 3. 피크 검출
- prominence 기반 피크 검출
- 상위 5개 피크 추출
- 주요 2개 성분 선택

### 4. V자 최저점 검출
- 오른쪽 피크에서 시작
- 순차적으로 파워가 감소하다가 증가하는 지점 검출
- 물리적으로 의미있는 분리점 제공

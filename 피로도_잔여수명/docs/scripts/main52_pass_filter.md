# main52_pass_filter.py - V자 최저점 기준 Pass Filter 적용

## 개요
main51_find_freq.py에서 검출한 V자 최저점을 기준으로 저대역/고대역 필터를 적용하여 압력 신호의 성분을 분리하는 스크립트입니다.

## 주요 기능
- **연속적인 필터 설계**: V자 최저점을 기준으로 저대역/고대역 완전 분리
- **신호 손실 방지**: 100% 마진으로 주파수 대역 간 Gap 제거
- **완벽한 신호 재구성**: Low Pass + High Pass = 원본 신호 (상관계수 1.0000)
- **에너지 보존**: 97% 이상의 높은 에너지 보존율
- **시각화**: 원본, 저대역, 고대역, 합성 신호 비교 그래프

## 입력 파일
- `data/raw/0470 소구역 압력 데이터.csv`
  - 0470 지역의 5분 간격 압력 측정 데이터
  
- `data/raw/0520 중구역 압력 데이터.csv`
  - 0520 지역의 5분 간격 압력 측정 데이터

### 입력 데이터 형식
```csv
DateTime,Pressure
2023-01-01 00:00:00,4.5
2023-01-01 00:05:00,4.3
...
```

## 필터 설정

### V자 최저점 기준
- **통합 기준**: 0.000030 Hz (553.5분 주기)
- 0520 중구역의 V자 최저점을 전체 시스템 기준으로 사용

### 필터 설계
- **저대역 필터**: Low Pass 0.000030 Hz
  - 553.5분 이하의 장주기 성분 추출
  - 일주조(1462.9분) 및 반일주조(731.4분) 포함
  
- **고대역 필터**: High Pass 0.000030 Hz
  - 553.5분 이상의 단주기 성분 추출
  - 빠른 압력 변동 및 노이즈 성분

### 필터 사양
- **필터 타입**: Butterworth 4차 필터
- **적용 방법**: filtfilt (양방향 필터링)
- **위상 지연**: 0 (양방향 필터링으로 제거)
- **차단 특성**: -24 dB/octave

## 데이터 처리 흐름
1. 압력 데이터 로드 (5분 간격)
2. V자 최저점 기준 설정 (553.5분)
3. 저대역/고대역 필터링 (V자 최저점 기준)
4. 신호 재구성 및 검증
5. 결과 시각화

## 알고리즘 세부사항

### 1. 데이터 전처리
- NaN 값 선형 보간
- 평균값 제거 (DC 성분 제거)

### 2. 필터 적용
```python
# 저대역 필터
sos_low = signal.butter(4, valley_freq, 'low', fs=sampling_rate, output='sos')
low_pass = signal.sosfiltfilt(sos_low, data)

# 고대역 필터  
sos_high = signal.butter(4, valley_freq, 'high', fs=sampling_rate, output='sos')
high_pass = signal.sosfiltfilt(sos_high, data)
```

### 3. 신호 재구성 검증
- 합성 신호 = 저대역 + 고대역
- 상관계수 계산으로 재구성 품질 확인

## 참고사항
- V자 최저점은 물리적으로 의미있는 분리 기준
- 완벽한 신호 재구성은 정보 손실이 없음을 보장
- 저대역은 주로 운영 패턴, 고대역은 과도 현상 반영

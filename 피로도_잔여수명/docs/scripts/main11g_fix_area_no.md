# main11g_fix_area_no.py

좌표 기반 중구역/소구역 번호 수정 스크립트

## 개요
CSV 파일의 잘못된 중구역번호와 소구역번호를 위도/경도 좌표를 이용해 올바른 값으로 수정합니다.
Shapefile과의 공간 조인(spatial join)을 통해 정확한 구역 번호를 자동으로 할당합니다.

## 입력 파일

### 필수 입력
1. **CSV 데이터**
   - 경로: `data/main11e_fix_error/*.csv`
   - 형식: UTF-8 BOM 인코딩 CSV
   - 필수 컬럼: ID, 작업일시, 위도, 경도, 파일타입, 공사명, 공사개요, 구군, 주소, 중구역번호, 소구역번호, 도로구분, 누수관경, 누수량, 용수구분, 용도구분

2. **Shapefile (중구역)**
   - 경로: `data/raw/export_shp_20250704(0520)/WEA_MDLZ_AS.shp`
   - 필드: MDZ_NUM (중구역 번호)
   - 좌표계: EPSG:5179

3. **Shapefile (소구역)**
   - 경로: `data/raw/export_shp_20250704(0520)/WEA_SMLZ_AS.shp`
   - 필드: SMZ_NUM (소구역 번호), MDZ_NUM (중구역 번호)
   - 좌표계: EPSG:5179

## 출력 파일

### CSV 파일
- **경로**: `results/main11g_fix_area_no/[원본파일명]_구역수정.csv`
- **형식**: UTF-8 BOM 인코딩 CSV
- **컬럼**: 원본과 동일한 16개 컬럼 (매칭 상태 컬럼 제외)
  - ID, 작업일시, 위도, 경도, 파일타입, 공사명, 공사개요, 구군, 주소
  - **중구역번호** (수정됨)
  - **소구역번호** (수정됨)
  - 도로구분, 누수관경, 누수량, 용수구분, 용도구분

## 주요 기능

### 1. 좌표계 변환
- WGS84 (EPSG:4326) → Korea 2000 / Central Belt 2010 (EPSG:5179)
- 위도/경도를 투영 좌표계로 변환하여 정확한 공간 매칭

### 2. 공간 조인 (Spatial Join)
- GeoPandas의 `sjoin` 함수 사용
- `predicate='within'`: 점이 폴리곤 내부에 있는지 확인
- left join으로 모든 레코드 유지

### 3. 구역 번호 매칭
- 중구역(MDLZ) 매칭: MDZ_NUM 필드 값으로 업데이트
- 소구역(SMLZ) 매칭: SMZ_NUM 필드 값으로 업데이트
- 소구역 shapefile의 MDZ_NUM도 활용하여 정확도 향상

### 4. 데이터 타입 처리
- 중구역번호: 정수 타입 (520)
- 소구역번호: 문자열 타입 (0243, 0490 등 앞자리 0 유지)

## 사용법

### 기본 사용
```bash
python src/main11g_fix_area_no.py
```

### 옵션
```bash
python src/main11g_fix_area_no.py --input <CSV파일경로> --region <지역코드> --output-dir <출력디렉토리>
```

- `--input`: 특정 CSV 파일 지정 (기본: data/main11e_fix_error/*.csv 자동 탐색)
- `--region`: 지역 코드 (기본: 0520)
- `--output-dir`: 출력 디렉토리 (기본: results/main11g_fix_area_no/)

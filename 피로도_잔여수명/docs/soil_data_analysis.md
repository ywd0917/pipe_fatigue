# Soil 데이터 분석

## 개요

`data/soil` 폴더에는 1:250,000 축척의 지질도 데이터가 4개의 shapefile로 구성되어 있습니다. 각 파일은 서로 다른 지질학적 요소를 표현하며, 모두 EPSG:4326 (WGS84) 좌표계를 사용합니다.

## 파일별 상세 분석

### 1. Geology_250K_Boudary.shp (지질 경계)

- **용도**: 암상 간의 경계선 표시
- **레코드 수**: 18,638개
- **지오메트리 타입**: LineString
- **주요 필드**:
  - `FID`: 고유 식별자
  - `TYPE`: 경계 유형 (3개 값)
    - 지질경계: 10,101개
    - 추정지질경계: 8,519개
    - 점이지질경계: 18개
  - `TYPENO`: 타입 번호 (1, 3)
  - `CLASS`: 분류 (모두 "암상경계")
  - `MAPNAME`: 도엽명
  - `MAPIDX`: 도엽 인덱스

### 2. Geology_250K_Fault.shp (단층)

- **용도**: 단층선 표시
- **레코드 수**: 1,433개
- **지오메트리 타입**: LineString
- **주요 필드**:
  - `TYPE`: 단층 유형 (3개 값)
    - 단층: 1,130개
    - 추정단층: 285개
    - 드러스트: 18개
  - `TYPENO`: 타입 번호
  - `MAPNAME`: 도엽명

### 3. Geology_250K_Frame.shp (도엽 프레임)

- **용도**: 지질도 도엽 경계
- **레코드 수**: 13개
- **지오메트리 타입**: Polygon, MultiPolygon
- **주요 필드**:
  - `FID`: 고유 식별자
  - `MAPIDX`: 도엽 인덱스
  - `MAPNAME`: 도엽명 (예: 남천점, 속초, 강릉, 서울, 대전 등)
  - `TYPENO`, `TYPE`: 타입 정보
  - `SURYEAR`: 측량 연도
  - `SURVEYOR`: 측량자

### 4. Geology_250K_Litho.shp (암상)

- **용도**: 지질 시대별 암상 분포
- **레코드 수**: 8,775개
- **지오메트리 타입**: Polygon, MultiPolygon
- **총 면적**: 99,243,668,927.41 평방미터
- **주요 필드**:
  - `fid`, `gid`: 식별자
  - `age`: 지질 시대 (14개 고유값)
    - 중생대 백악기: 3,288개
    - 선캄브리아시대: 1,966개
    - 신생대 제4기: 1,133개
    - 중생대 쥐라기: 974개
    - 시대 미상: 930개
    - 기타 9개 시대: 484개
  - `lithoidx`: 암상 인덱스 (246개 고유값)
    - 평균 35.7개 객체/lithoidx
    - 최대 객체 수: Kav (유문암및유문암질응회암) - 1,172개
    - 최대 면적: Jgr (화강암) - 18,559,770,070.15 평방미터
  - `lithoname`: 암상명
  - `mapidx`, `mapname`: 도엽 정보 (13개 도엽)
    - 강릉, 광주, 남천점, 대전, 목포, 백아도, 부산, 서울, 속초, 안동, 여수, 제주, 진남포
  - `shape_area`, `shape_len`: 면적 및 둘레 정보

## 시각화 시 고려사항

### 레이어 구성
1. **배경 레이어**: Frame (도엽 경계)
2. **주요 레이어**: Litho (암상 분포)
3. **오버레이 레이어**: Boundary (경계선), Fault (단층선)

### 그룹화 옵션
- **Boundary**: TYPE별 그룹화 (3개 타입)
- **Fault**: TYPE별 그룹화 (3개 타입)
- **Frame**: MAPNAME별 표시 (13개 도엽)
- **Litho**: 
  - age별 그룹화 (14개 지질시대)
  - lithoidx별 그룹화 (246개 암상, 색상 구분 어려움)

### 인코딩 이슈
- Litho 파일: UTF-8 인코딩 사용
- 기타 파일(Boundary, Fault, Frame): EUC-KR 인코딩 사용
- 파일별로 다른 인코딩을 사용하므로 주의 필요

## main3_draw_soil.py 구현 권장사항

### 기본 기능
1. 전체 통합 시각화 (옵션 없을 때)
   - Frame을 배경으로
   - Litho를 age별로 색상 구분하여 표시
   - Boundary와 Fault를 선으로 오버레이

2. 개별 파일 시각화 (`--file` 옵션)
   - 선택한 파일만 표시
   - 적절한 그룹화 필드 자동 선택

### 추가 옵션
- `--group-by`: 그룹화 필드 선택
- `--layer`: 특정 레이어만 표시 (boundary, fault, frame, litho)
- `--show-frame`: Frame 배경 표시 여부
- `--output`: 출력 파일 경로
- `--title`: 그래프 제목

### 색상 구성
- **Litho (age별)**: 14개 구별 가능한 색상 팔레트
- **Boundary**: TYPE별 3개 선 스타일 (실선, 점선, 대시선)
- **Fault**: TYPE별 3개 색상 (빨강 계열)
- **Frame**: 연한 회색 배경

### 범례 표시
- 각 레이어별 범례 구성
- age나 TYPE 값에 따른 범례 자동 생성
- lithoidx의 경우 246개로 너무 많아 상위 15개만 표시
- 한글 폰트 설정 필요

## main4_list_soil.py 스크립트

lithoidx별 상세 정보를 분석하고 출력하는 스크립트가 추가되었습니다.

### 주요 기능
- lithoidx별 암상 정보 분석 및 출력
- 면적 기준 정렬 및 순위 표시
- 지질시대별 분포 및 도엽 정보 표시
- CSV 파일 저장 기능
- 특정 암상명 또는 lithoidx 검색 기능

### 사용 예시
```bash
# 상위 10개만 출력
python src/main4_list_soil.py --top 10

# 특정 암상 검색
python src/main4_list_soil.py --search "화강암"

# CSV 파일로 저장
python src/main4_list_soil.py --csv --output results/lithoidx_analysis.csv

# 전체 통계만 출력
python src/main4_list_soil.py --summary
```

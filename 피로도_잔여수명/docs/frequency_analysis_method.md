# 주파수 분석 방법론 (main51_find_freq.py)

## 개요
본 문서는 압력 데이터에서 주요 주파수 성분을 식별하고 분리하기 위한 분석 방법론을 설명합니다.

## 1. 데이터 전처리

### 1.1 데이터 로드 및 정렬
- CSV 파일에서 압력 데이터(`wtrprsr`)와 측정 시간(`msrmt_dt`) 로드
- 시간순으로 데이터 정렬
- 샘플링 주파수: 1/300 Hz (5분 간격)

### 1.2 NaN 값 처리
- `interpolate_nan_values()` 함수를 통한 선형 보간
- 시계열 연속성 유지를 위한 보간 처리

## 2. 주파수 도메인 분석

### 2.1 파워 스펙트럼 밀도(PSD) 계산
- `analyze_dominant_frequencies()` 함수 사용
- Welch's method를 통한 PSD 추정
- 주파수별 파워 분포 분석

### 2.2 주요 피크 검출
- PSD에서 가장 강한 2개의 피크 식별
- 각 피크의 주파수와 주기(분) 계산
- 저주파 성분과 고주파 성분 구분

### 2.3 V자 최저점 검출
- 두 주요 피크 사이의 최소 PSD 지점 탐색
- 필터 설계의 기준점으로 활용
- 오른쪽 V자 최저점 우선 탐색

## 3. 필터 설계

### 3.1 성분 분리 전략
```
주파수 갭 = 고주파 성분 - 저주파 성분
```

### 3.2 차단 주파수 결정
- **저대역 필터 (Low Pass)**
  - 차단 주파수 = 저주파 + (주파수 갭 × 0.6)
  - 저주파 성분 추출용
  
- **고대역 필터 (High Pass)**
  - 차단 주파수 = 저주파 + (주파수 갭 × 0.4)
  - 고주파 성분 추출용

### 3.3 Butterworth 필터 적용
- 4차 Butterworth 필터 사용
- `signal.butter()` 및 `signal.filtfilt()` 활용
- 위상 왜곡 없는 필터링 (zero-phase filtering)

## 4. 성분 분리 프로세스

### 4.1 필터 적용
1. Low Pass 필터로 저대역 성분(Component 1) 추출
2. High Pass 필터로 고대역 성분(Component 2) 추출
3. 각 성분의 표준편차 계산으로 분리 품질 검증

### 4.2 분리 결과 검증
- 원본 신호와 분리된 성분 비교
- 각 성분의 주기적 특성 확인
- 표준편차를 통한 에너지 분포 분석

## 5. 시각화

### 5.1 주파수 스펙트럼 플롯
- **로그 스케일 플롯**: 전체 주파수 범위 표시
- **선형 스케일 플롯**: 저주파 영역 상세 표시 (0.0002 Hz까지)
- 주요 피크와 V자 최저점 표시

### 5.2 성분 분석 플롯 (6개 서브플롯)
1. 로그 스케일 파워 스펙트럼
2. 선형 스케일 저주파 영역
3. 원본 시계열 데이터
4. 분리된 성분 중첩 표시
5. 저대역 성분 상세
6. 고대역 성분 상세

## 6. 물리적 의미

### 6.1 주파수 성분의 해석
- **저대역 성분**: 장주기 변동 (일간/주간 패턴)
- **고대역 성분**: 단주기 변동 (시간 단위 변화)

### 6.2 V자 최저점의 의미
- 두 주요 성분 간의 자연스러운 분리 지점
- 물리적으로 의미있는 필터 경계
- 예: 0520 중구역의 경우 약 553.5분 주기

## 7. 출력 결과

### 7.1 FilterDesign 객체
```python
FilterDesign(
    low_freq_component: FilterComponent(
        target_freq,          # 목표 주파수
        target_period_min,    # 목표 주기(분)
        filter_type,         # 'low_pass'
        cutoff_freq,         # 차단 주파수
        cutoff_period_min    # 차단 주기(분)
    ),
    high_freq_component: FilterComponent(...)
)
```

### 7.2 분리된 성분
- Component 1: 저대역 필터링된 신호
- Component 2: 고대역 필터링된 신호

| 파라미터 | 값 | 설명 |
|---------|---|------|

| 필터 차수 | 4 | Butterworth 필터 |

# Pass Filter 적용 방법론 (main52_pass_filter.py)

## 개요

V자 최저점(Valley Point)을 기준으로 압력 데이터를 저대역과 고대역 성분으로 분리하는 필터링 방법론을 설명합니다.

## 1. V자 최저점 기반 필터 설계

### 1.1 V자 최저점 정의

- **주파수**: 3.0e-05 Hz
- **주기**: 553.5분 (약 9.2시간)
- 두 주요 주파수 성분 사이의 최소 PSD 지점
- 물리적으로 의미있는 분리 경계

### 1.2 필터 차단 주파수 설정

```python
# 저대역 필터 (Low Pass)
저대역_차단주파수 = V자_최저점_주파수 × 1.2  # 20% 마진

# 고대역 필터 (High Pass)
고대역_차단주파수 = V자_최저점_주파수 × 0.8  # 20% 마진
```

## 3. 성능 검증 메트릭

### 3.1 통계적 분석

- **평균값**: 각 성분의 평균
- **표준편차**: 신호 변동성 측정
- **분산**: 에너지 분포 계산

### 3.2 에너지 분포 분석

```python
에너지_비율 = (성분_분산 / 원본_분산) × 100
```

- 저대역 에너지 비율
- 고대역 에너지 비율
- 총 에너지 보존율 (이상적: 100%)

### 3.3 상관계수 분석

- 원본 신호와 합성 신호의 상관관계
- 필터링 품질 지표

## 4. 시각화 구성

### 4.1 단일 그래프 중첩 표시

- **(1) 원본 데이터**: 검정색 실선
- **(2) 저대역 성분**: 빨간색 실선
- **(3) 고대역 성분**: 파란색 실선
- **(4) 합성 신호**: 초록색 점선

### 4.2 시각화 범위 설정

```python
시작_인덱스 = min(10000, 전체_길이 × 0.2)
종료_인덱스 = 시작_인덱스 + 1000
```

- 전체 데이터의 20% 지점부터
- 1000개 데이터 포인트 표시

### 4.3 통계 정보 표시

- 각 성분의 평균 및 표준편차
- V자 최저점 정보
- 텍스트 박스로 그래프 내 표시

## 5. 품질 관리

### 5.1 에너지 보존율 검증

- **정상 범위**: 95% ~ 105%
- **경고 조건**:
  - < 95%: 에너지 손실 (필터 설계 재검토 필요)
  - > 105%: 신호 중복 가능성

### 5.2 필터 마진 파라미터

| 파라미터 | 값 | 설명 |

| HIGH_PASS_MARGIN | 0.8 | 고대역 필터 마진 (20% 여유) |

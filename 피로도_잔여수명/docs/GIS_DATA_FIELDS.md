# GIS 데이터 필드 정의

이 문서는 fatigue-qgis 프로젝트에서 사용되는 GIS 데이터 테이블의 필드(헤더) 정의를 설명합니다.

## 개요

본 프로젝트의 GIS 데이터는 상수도 관망 시설물 정보를 포함하고 있으며, 각 필드는 시설물의 식별, 분류, 물리적 속성, 위치 정보 등을 나타냅니다.

## 명확하게 확인된 필드 정의

### 1. 필드명과 용도

| 필드명 | 용도 | 설명 |
|--------|------|------|
| **FTR_CDE** | 시설물 분류 코드 | 데이터 그룹화의 기준으로 사용되는 주요 분류 코드 |
| **FTR_IDN** | 시설물 식별자 | 각 시설물의 고유 식별 번호 |
| **MOP_CDE** | 재질 코드 | 관의 재질을 나타내는 코드 (코드에서 "재질"로 명시) |
| **STD_DIP** | 관경 | 관의 직경 정보 (코드에서 "관경"으로 명시) |
| **HJD_CDE** | 법정동 코드 | 시설물의 위치를 나타내는 10자리 행정구역 코드 |
| **IST_YMD** | 설치일자 | 시설물의 설치일자 (YYYYMMDD 형식) |
| **geometry** | 공간 정보 | 시설물의 위치 및 형상 정보 |
| **SHT_NUM** | 도엽번호 | 도면 시트 번호 |
| **MNG_CDE** | 관리코드 | 시설물 관리 코드 |
| **GIS_IDN** | GIS 식별번호 | GIS 시스템 내 고유 식별번호 |
| **FTC_CDE** | 시설물 유형 코드 | Feature Type Code |
| **GU_CDE** | 구 코드 | 행정구역(구) 코드 |
| **SMZ_LBL** | 소블록 라벨 | 소블록 구역의 라벨 |
| **SMZ_NUM** | 소블록 번호 | 소블록 구역 번호 |
| **MDZ_NUM** | 중블록 번호 | 중블록 구역 번호 |
| **LGZ_NUM** | 대블록 번호 | 대블록 구역 번호 |
| **OMZ_NUM** | 관리구역 번호 | Operation/Management Zone 번호 |
| **SCD_NUM** | 2차구역 번호 | Secondary Zone 번호 |
| **CRE_CHK** | 생성 확인 | 데이터 생성 확인 플래그 |
| **SAW_CHK** | 검토 확인 | 데이터 검토 확인 플래그 |

### 2. 데이터 형식

| 필드명 | 데이터 타입 | 예시값 |
|--------|------------|--------|
| **FTR_CDE** | 문자열 | "SA001", "SA002", "SA119", "SA200", "EA006" 등 |
| **FTR_IDN** | 실수 | 12345.0, 67890.0, 11111.0 |
| **HJD_CDE** | 문자열 (10자리) | "2723063000" |
| **IST_YMD** | 문자열 (8자리) | "20230101" |
| **FTC_CDE** | 문자열 | (값 미확인) |
| **SAA_CDE** | 문자열 | (값 미확인) |

### 3. 기능적 역할

- **FTR_CDE**: 
  - 데이터를 그룹화하는 기준 필드
  - 통계 집계의 주요 키
  - 시설물 유형별 분류에 사용

- **geometry**: 
  - Point: 점 형태의 시설물 (좌표)
  - LineString: 선 형태의 시설물 (길이 계산 가능)
  - Polygon: 면 형태의 시설물 (면적 계산 가능)

### 4. FTR_CDE 코드 정의

프로젝트에서 사용되는 FTR_CDE 코드와 해당 시설물 유형:

| FTR_CDE | 시설물 유형 | 파일명 | 설명 |
|---------|------------|--------|------|
| **SA001** | 상수관로 | V_WTL_PIPE_LM | 배수관로 (Water Line Pipe) |
| **SA002** | 급수관 | V_WTL_SPLY_LS | 급수관로 (Water Supply Line) |
| **SA119** | 소화전 | WTL_FIRE_PS | 소방용 급수전 (Fire Hydrant) |
| **SA200** | 일반 밸브 | WTL_VALV_PS | 일반적인 밸브 (전체의 88%) |
| **SA202** | 특수 밸브 | WTL_VALV_PS | 특수 목적 밸브 |
| **SA203** | 밸브실 | WTL_VALV_PS | 밸브 보호 구조물 (치수 정보 포함) |
| **EA006** | 대블록 | WEA_LRGZ_AS | 대블록 구역 (Large Zone) |
| **EA007** | 중블록 | WEA_MDLZ_AS | 중블록 구역 (Middle Zone) |
| **EA008** | 소블록 | WEA_SMLZ_AS | 소블록 구역 (Small Zone) |
| **EA009** | 2차구역 | WEA_SCDZ_AS | 2차 구역 (Secondary Zone) |

**코드 체계 설명**:
- **SA 코드**: 상수도 시설물 (Sangsu-do Assets)
- **EA 코드**: 구역/영역 정보 (Equipment Area)

## 추정되는 필드 정의

### 1. 약어의 의미 (일반적인 GIS 명명 규칙 기반)

| 약어 | 추정 의미 (영문) | 추정 의미 (한글) |
|------|------------------|------------------|
| **FTR** | Feature | 시설물 |
| **CDE** | Code | 코드 |
| **IDN** | Identification Number | 식별번호 |
| **FTC** | Feature Type Code | 시설물 유형 코드 |
| **SAA** | Service Area / Sub-Area | 서비스 구역 / 하위 구역 |
| **MOP** | Material of Pipe | 관 재질 |
| **STD** | Standard | 표준 |
| **DIP** | Diameter of Pipe | 관 직경 |

### 2. 데이터의 성격 (추정)

- **FTR_CDE의 "SA" 접두사**: 
  - 상수도(Sangsu-do) 관련 시설물로 추정
  - SA001, SA002 등은 상수도 시설물의 세부 분류

### 3. 전체 데이터 구조

이 GIS 데이터는 상수도 관망 시설물 관리 시스템의 일부로 보이며, 다음과 같은 정보를 포함:
- 시설물 식별 및 분류 (FTR_CDE, FTR_IDN)
- 위치 정보 (HJD_CDE, geometry)
- 물리적 속성 (MOP_CDE, STD_DIP)
- 시간 정보 (IST_YMD)
- 관리 정보 (FTC_CDE, SAA_CDE)

## Zone 구역 정의

### Zone 파일 유형

프로젝트에는 다음과 같은 Zone 구역 파일들이 존재합니다:

| 파일명 패턴 | Zone 유형 | 한글명 | 설명 |
|-------------|-----------|--------|------|
| **WEA_LRGZ_AS** | LRGZ | 대블록 | Large Zone - 가장 큰 단위의 구역 |
| **WEA_MDLZ_AS** | MDLZ | 중블록 | Middle Zone - 중간 단위의 구역 |
| **WEA_SCDZ_AS** | SCDZ | 2차구역 | Secondary Zone - 보조 구역 |
| **WEA_SMLZ_AS** | SMLZ | 소블록 | Small Zone - 가장 작은 단위의 구역 |

### Zone 계층 구조

Zone은 계층적 구조를 가지며, 상위 Zone이 하위 Zone을 포함하는 관계입니다:

```
LRGZ (대블록)
  └── MDLZ (중블록)
        └── SCDZ (2차구역)
              └── SMLZ (소블록)
```

### Zone별 주요 필드

각 Zone 파일에 포함된 주요 필드들:

| Zone 유형 | 고유 라벨 필드 | 번호 필드 | 설명 |
|-----------|---------------|-----------|------|
| **LRGZ** | - | LGZ_NUM | 대블록 번호 (예: X0, D0) |
| **MDLZ** | - | MDZ_NUM | 중블록 번호 (예: 0901, 0902) |
| **SCDZ** | - | SCD_NUM | 2차구역 번호 |
| **SMLZ** | SMZ_LBL | SMZ_NUM | 소블록 라벨 및 번호 (예: 1, 2, 5) |

### 기타 Zone 관련 파일

| 파일명 패턴 | 설명 |
|-------------|------|
| **WEA_FIRE_AS** | 소방 급수 관련 구역 |
| **WEA_VALV_AS** | 밸브 위치 정보 |
| **WEA_SPLY_AS** | 공급(Supply) 관련 정보 |

### Zone 시각화 특징

- **색상 구분**: 각 Zone 유형별로 고유한 색상 지정
  - LRGZ: 빨강 (#FF0000)
  - MDLZ: 파랑 (#0000FF)  
  - SCDZ: 초록 (#00AA00)
  - SMLZ: 주황 (#FF8800)
- **경계선 표시**: 모든 Zone은 경계선으로 표시
- **내부 색칠**: 개별 Zone 표시 시 투명도 0.2로 내부 색칠
- **라벨 표시**: 각 Zone의 중심점에 번호/라벨 표시

## 참고사항

1. 이 문서의 "추정" 부분은 일반적인 GIS 및 상수도 시설물 데이터의 명명 규칙을 기반으로 작성되었습니다.

2. 정확한 필드 정의를 확인하려면 다음 자료를 참조하시기 바랍니다:
   - 해당 GIS 시스템의 데이터 사전(Data Dictionary)
   - 시설물 관리 시스템의 메타데이터 문서
   - 관련 표준 규격서

3. 프로젝트 진행 중 새로운 필드가 발견되거나 정확한 의미가 확인되면 이 문서를 업데이트해 주시기 바랍니다.

## 개요

재작업 위치 주변에는 여러 개의 파이프가 존재할 수 있습니다. 거리 임계값(예: 30m) 내의 파이프들 중에서 어떤 값을 선택할지 결정하는 것이 매칭 전략입니다.

### 왜 여러 전략이 필요한가?

- **단일 파이프만 고려하면**: 주변 인프라의 영향을 놓칠 수 있음
- **모든 파이프를 동일하게 고려하면**: 거리의 중요성을 무시하게 됨
- **극값만 고려하면**: 노이즈에 민감해질 수 있음

## nearest 전략 - 가장 가까운 파이프

### 개념
재작업 위치에서 가장 가까운 파이프 하나만 선택하여 그 파이프의 K-factor 값을 사용합니다.

### 수식
```
K_factor(nearest) = K_factor(pipe_i) where distance(pipe_i) = min(distances)
```

### 구현
```python
# 가장 가까운 파이프 찾기
nearest_pipe = min(pipes_within_range, key=lambda p: p["distance"])
result[f"nearest_{factor}"] = nearest_pipe.get(factor, 0)
```

### 특징
- **장점**: 
  - 직관적이고 명확한 매칭
  - 계산이 단순함
  - 가장 직접적인 영향 반영
- **단점**: 
  - 주변 파이프들의 영향 무시
  - 측정 오류에 민감
  - 네트워크 효과 반영 못함

## max 전략 - 최대값 선택

### 개념
거리 임계값 내의 모든 파이프 중에서 K-factor가 가장 큰 값을 선택합니다.

### 수식
```
K_factor(max) = max(K_factor(pipe_i)) for all pipes where distance(pipe_i) ≤ threshold
```

### 구현
```python
# 범위 내 최대값 선택
result[f"max_{factor}"] = max(p.get(factor, 0) for p in pipes_within_range)
```

### 특징
- **장점**: 
  - 최악의 조건 반영 (보수적 접근)
  - 위험 요소 강조
  - 안전 마진 확보
- **단점**: 
  - 극값에 과도하게 민감
  - 평균적 상태 무시
  - 이상치의 영향 과대

## avg 전략 - 거리 가중 평균

### 개념
거리 임계값 내의 모든 파이프를 고려하되, 거리에 반비례하는 가중치를 적용하여 평균을 계산합니다.

### 수식

#### 가중치 계산
```
weight_i = 1 / (distance_i + 1)
```
- distance_i: i번째 파이프까지의 거리 (미터)
- +1: 거리가 0일 때 무한대 방지

#### 가중 평균 계산
```
K_factor(avg) = Σ(weight_i × K_factor_i) / Σ(weight_i)
```

### 구현
```python
# 거리 가중 평균 계산
total_weight = 0
weighted_sum = 0
for p in pipes_within_range:
    weight = 1 / (p["distance"] + 1)  # 거리가 0일 때를 위해 1 추가
    weighted_sum += weight * p.get(factor, 0)
    total_weight += weight
result[f"avg_{factor}"] = weighted_sum / total_weight if total_weight > 0 else 0
```

### 가중치 예시
| 거리 | 가중치 | 상대 비중 |
|------|--------|-----------|
| 0m   | 1.000  | 100%      |
| 5m   | 0.167  | 16.7%     |
| 10m  | 0.091  | 9.1%      |
| 20m  | 0.048  | 4.8%      |
| 30m  | 0.032  | 3.2%      |

### 특징
- **장점**: 
  - 균형잡힌 평가
  - 거리의 중요성 반영
  - 노이즈와 이상치에 강건
  - 네트워크 효과 포착
- **단점**: 
  - 계산이 복잡함
  - 파라미터(가중치 함수) 선택 필요
  - 해석이 덜 직관적

## 전략 비교

### 개념적 비교

| 측면 | nearest | max | avg |
|------|---------|-----|-----|
| **고려 파이프 수** | 1개 | 모든 파이프 | 모든 파이프 |
| **거리 민감도** | 매우 높음 | 없음 | 중간 |
| **이상치 영향** | 낮음 | 매우 높음 | 낮음 |
| **계산 복잡도** | O(n) | O(n) | O(n) |
| **해석 용이성** | 높음 | 중간 | 낮음 |

### 사용 시나리오

| 상황 | 권장 전략 | 이유 |
|------|-----------|------|
| **정밀 위치 데이터** | nearest | 위치가 정확하면 가장 가까운 파이프가 주 원인 |
| **안전성 평가** | max | 최악 조건 고려가 중요 |
| **종합적 분석** | avg | 주변 전체 상태가 영향 |
| **네트워크 분석** | avg | 파이프 간 상호작용 고려 |

## 권장 사항

### 1. 기본 권장: avg 전략
- **이유**: 
  - 가장 높은 상관관계
  - 노이즈에 강건
  - 네트워크 효과 반영
  - 실제 현상과 부합 (재작업은 주변 전체 상태의 영향)

### 2. 상황별 선택
- **빠른 분석 필요**: nearest 전략 (계산 단순, 해석 용이)
- **위험 평가**: max 전략 (보수적 접근)
- **정밀 분석**: avg 전략 (종합적 평가)

### 3. 거리 임계값 설정
- **10m**: 정밀 분석, 높은 신뢰도 필요 시
- **20m**: 통계적 최적 (main14b2 분석 결과)
- **30m**: 일반적 분석, 충분한 매칭률 확보

### 4. 구현 시 주의사항
```python
# 가중치 함수 선택 예시
weight = 1 / (distance + 1)           # 기본 (현재 사용)
weight = 1 / (distance + 0.1)         # 더 급격한 감소
weight = exp(-distance / 10)          # 지수 감소
weight = 1 / (1 + distance**2)        # 제곱 반비례
```
